# Java GUI Basics

A beginner-friendly Java Swing project created to explore the fundamentals of graphical user interfaces (GUI).

## Features

- Create a window using `JFrame`
- Organize components using `JPanel`
- Display text using `JLabel`
- Get user input using `JTextField`
- Handle button clicks using `JButton` and `ActionListener`
- Display dynamic messages using `setText()`

## Technologies

- Java
- Java Swing
- Java AWT

## How to Run

1. Clone the repository.
2. Open the project in your IDE.
3. Run `MyFirstGUI.java`.
